# 競艇 期待値ツール（`/kyotei`）

## 最初に：このツールが「できないこと」

**「買えば高確率で利益が出る」ツールは作れません。** 数学的な理由があります。

舟券はパリミュチュエル方式で、売上から約25%（控除率）が引かれた残りが払戻に回ります。
つまり**全通り買えば必ず約25%負けます**。オッズは他の購入者の投票で決まるので、
「よく当たる予想」を作っても、同じことに気づいた人が買えばオッズが下がり、旨みは消えます。

「高確率で当たる」と「利益が出る」も別物です。1号艇の単勝はおよそ55%当たりますが、
その分オッズは1.2〜1.5倍程度にしかならず、回収率は1を超えません。
**的中率を上げても、控除率は消えません。**

長期でプラスにする方法はひとつだけです:

> **市場（オッズ）が付けている確率より、自分の見積もりのほうが正確な買い目を見つけ、
> そこだけ買って、それ以外を全部見送る。**

このツールは「当てる」ためではなく、**その判断と資金配分を機械化し、
本当に優位性があるのかを検証する**ためのものです。多くのレースは「見送り」になります。
見送りは損ではありません。控除率25%の支払いを回避した分だけ得をしています。

## 使い方

### 1. 出走表とオッズを入れる（`/kyotei`）

- 出走表: 枠・級別・全国勝率・当地勝率・モーター2連率・ボート2連率・平均ST・展示タイム。前付けがあれば進入コースも。
- オッズ: **締切直前のもの**を1点1行で貼り付け（`1-2-3 7.4`）。
  早い時間のオッズで判断すると、実際には買えない配当で「勝った」ことになってしまいます。

### 2. 資金とルールを決める

| 設定 | 意味 | 目安 |
|---|---|---|
| 資金 | 失っても生活に影響しない額 | — |
| ケリー係数 | 1 = フルケリー | **0.25以下**。確率の見積もりが少し甘いだけでフルケリーはオーバーベットになります |
| 最低期待値 | この値を超える買い目だけ買う | 1.15〜1.3 |
| モデルの信用度 | 1 = 自分のモデルだけ / 0 = 市場だけ | 較正前は 0.5 以下 |
| 1レースの最大点数 | 点数を増やすほど控除率をそのまま払う | 少なめ |

### 3. 検証する（ここが本題）

同じルールを過去レースに当てはめて、**回収率が1を超えるか**を確認します。
超えないなら、そのルールでは本番でも負けます。設定を変えるか、賭けないかの二択です。

検証結果の読み方:

- **回収率 (ROI)**: 払戻 ÷ 投票額。無策なら 0.75 に収束します。
- **t 値**: |t| < 2 なら、そのプラスもマイナスも**偶然の範囲**です。舟券の収支は分散が非常に大きく、
  数百レースのプラスは普通に偶然で出ます。「必要レース数」の表示も見てください。
- **最大ドローダウン**: 途中でどこまで資金が減ったか。ここに耐えられないなら、その賭け方は現実的ではありません。
- **モンテカルロ**: 同じ成績が続いたとして「1,000レース後にプラスで終わっている確率」と「破産確率」。
  **「高確率で利益」と言えるのは、この確率が高く、破産確率が十分低いときだけです。**

同梱の合成サンプルは動作確認用の**架空データ**です。実際のレース結果ではないので、
そこでの成績はこのツールの有効性の証拠にはなりません。

### データを自分で集める

判断に使えるのは、自分で集めた実データだけです。必要なのは1レースにつき3つ:

1. 出走表（選手・モーター・ボートの成績）
2. **締切直前**のオッズ（全組番）
3. 確定着順

ボートレース公式サイトが番組表・競走成績を公開しています。オッズは締切直前に自分で記録する必要があります
（結果データには「その時点のオッズ」が残らないため）。集めたデータを次の形式の JSON 配列にすると、
検証パネルの「自分のデータ（JSON）を読み込む」でそのまま使えます。

```jsonc
[
  {
    "card": {
      "id": "2026-09-04-suminoe-1",
      "venue": "住之江",
      "date": "2026-09-04",
      "raceNumber": 1,
      "entries": [
        {
          "lane": 1, "klass": "A1", "racerName": "…",
          "nationalWinRate": 6.82, "localWinRate": 6.50,
          "motor2nd": 41.2, "boat2nd": 35.0,
          "avgStartTiming": 0.14, "exhibitionTime": 6.72
        }
        // …6艇ぶん
      ]
    },
    "odds": { "trifecta": { "1-2-3": 7.4, "1-3-2": 12.1 /* …120点 */ } },
    "result": { "first": 1, "second": 2, "third": 3 }
  }
]
```

## 中身

`src/lib/kyotei/` は UI から独立した純関数の集まりです。

| モジュール | 役割 |
|---|---|
| `courseStats.ts` | コース別1着率。競艇は進入コースで勝率がほぼ決まるので、これがモデルの土台 |
| `model.ts` | 出走表 → 各艇の強さスコア → 着順確率（Plackett–Luce + Henery 指数） |
| `calibrate.ts` | 過去レースから重みを最尤推定（勾配上昇）。**使う前に必ず較正すること** |
| `ev.ts` | オッズから控除率と市場の含意確率を復元し、期待値を計算 |
| `kelly.ts` | 排反な複数買い目への同時ケリー配分（Smoczynski–Tomkins の解析解） |
| `plan.ts` | 上記をまとめて「買う/見送る」と購入金額を決める |
| `backtest.ts` | 過去レースでの回収率・的中率・最大DD・t値 |
| `montecarlo.ts` | 資金曲線のブートストラップ。利益確率と破産確率 |

### モデル

各艇のスコアは

```
score = log(そのコースの1着率)           ← 競艇の構造そのもの
      + w1・(全国勝率 - 5.5) + w2・(当地勝率 - 5.5)
      + w3・(モーター2連率 - 35)/10 + w4・(ボート2連率 - 35)/10
      + w5・(0.16 - 平均ST)×10
      + w6・級別ポイント
      + w7・(レース内平均展示タイム - 展示タイム)×10
```

1着は `exp(score)` に比例して選ばれ、2着は残り5艇の中で同じ規則で選ばれます（Plackett–Luce）。
2着・3着の抽選ではスコアに指数 λ<1 を掛けて実力差を鈍らせます（Henery モデル）。
素の Plackett–Luce は「強い艇が2・3着にも来る確率」を過大評価するためです。

`DEFAULT_WEIGHTS` は**実データで当てはめた値ではありません**。`calibrateWeights()` で自分のデータに較正してください。
較正結果は「コース別成績だけのベースライン」と対数損失で比較され、勝てていなければモデルに意味はありません。

### 期待値とケリー

- 期待値 = 確率 × オッズ。1.0 でトントン。1.0 を超える買い目が1点も無ければ見送ります。
- モデル確率と市場含意確率は幾何ブレンドします（`marketBlend`）。
  オッズは多数の予想が集約された強い予測なので、較正前のモデルを丸ごと信じると
  較正ズレがそのまま「偽の妙味」に化けます。
- 賭け金は同一レース内の複数買い目に対する対数資産最大化の厳密解（ケリー）で決め、
  ケリー係数・1点上限・1レース上限・100円単位の切り捨てを適用します。

## API

```
POST /api/kyotei/plan
{
  "card":    { "entries": [ /* 6艇 */ ] },
  "odds":    { "trifecta": { "1-2-3": 7.4, "…": 0 } },
  "options": { "bankroll": 200000, "minEdge": 0.15, "marketBlend": 0.5, "maxTickets": 6, "fraction": 0.25 }
}
```

返り値は `skip`（見送りか）、`reasons`、`tickets`（組番・金額・オッズ・期待値）、
`winProbability`、`market`（控除率・オッズ取得率）、`topCandidates`（期待値上位20点）。

## 注意

- 舟券の購入は20歳以上に限られます。賭けは必ず余剰資金の範囲で行ってください。
- このツールは投資助言ではありません。使った結果の損失について責任は負えません。
- のめり込みや借金に心当たりがある場合は、公益社団法人ギャンブル依存症問題を考える会などの相談窓口を利用してください。
