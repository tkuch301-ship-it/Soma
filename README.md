# Soma — 面接トーク練習アプリ

就活の面接で「話が長い」と指摘された人のための、話し方トレーニングアプリです。
想定質問に声で答えると、その場で回答を分析して数値でフィードバックします。

## できること

- **想定質問への回答練習** — 自己紹介・ガクチカ・志望動機などの定番質問に、目標時間(30〜120秒)を決めて回答
- **リアルタイム文字起こし** — ブラウザの Web Speech API による日本語音声認識
- **自動分析** — 以下を計測して100点満点でスコア化
  - 話した時間と目標時間の超過率
  - 話速(字/分。聞き取りやすい目安は250〜350)
  - 言いよどみ(「えーと」「あの」「なんか」など)の回数
  - 冗長な言い回し(「〜という形で」「〜だと思っていて」など)の回数
  - 一文の平均の長さ(長い文はダラダラ話しているサイン)
- **改善アドバイス** — 崩れている項目に応じた具体的な指摘
- **練習の記録** — スコアの推移グラフと一覧

## 使い方

`index.html` 1枚だけの静的Webアプリです。ビルドも依存ライブラリもありません。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を Chrome で開く
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを選ぶだけで動きます。

## 動作環境

- **Chrome / Edge**(Web Speech API の日本語認識に対応しているブラウザが必要です。Safari・Firefox では動きません)
- マイクの使用許可が必要です
- 音声認識は「えー」などの言いよどみを取りこぼすことがあります。数値は目安として使ってください

## データの扱い

音声は端末のマイクからブラウザの音声認識機能に直接渡され、このアプリが録音を保存することはありません。
練習の記録(スコア・時間・回数)は端末内の localStorage にのみ保存され、外部に送信されません。

※ Chrome の音声認識は、実装上その音声を Google のサーバーで処理します(ブラウザ標準の挙動)。

## 実装メモ

- 言いよどみと冗長表現は、長い語を優先する単一スキャンで検出しています。
  「あのー」を「あの」と二重に数えたり、「やっぱり」を「やっぱ」と重複計上したりしないためです。
  検出結果(span)はカウントと文字起こしのハイライトで共有しているので、数字と色が必ず一致します。
- 認識できた文字数が閾値(12文字)未満の回は、採点せず記録にも残しません。
  無音のまま終了したときに高得点が出てしまうのを防いでいます。
