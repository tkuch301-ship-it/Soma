# Soma — 面接トーク練習アプリ

就活の面接で「話が長い」と指摘された人のための、話し方トレーニングアプリです。
想定質問に声で答えると、その場で回答を分析して数値でフィードバックします。

## できること

- **想定質問への回答練習** — 自己紹介・ガクチカ・志望動機などの定番質問に、目標時間(30〜120秒)を決めて回答
- **リアルタイム文字起こし** — ブラウザの Web Speech API による日本語音声認識(録音データは端末外に送信されません)
- **自動分析** — 以下をルールベースで計測してスコア化(100点満点)
  - 話した時間と目標時間の超過率
  - 話速(字/分。目安は250〜350)
  - フィラー語(「えーと」「あの」「なんか」など)の回数
  - 冗長表現(「〜という形で」「〜だと思っていて」など)の回数
  - 一文の平均の長さ(長い文=ダラダラ話すサイン)
- **アドバイス表示** — 計測結果に応じた具体的な改善アドバイス
- **練習履歴** — スコアの推移グラフと記録一覧(localStorage に保存)

## 使い方

サーバー不要の静的Webアプリです。

```bash
# ローカルで起動(例)
python3 -m http.server 8000
# → http://localhost:8000 を Chrome で開く
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを指定するだけで動きます。

## 動作環境

- **Chrome / Edge 推奨**(Web Speech API の日本語認識が必要です)
- マイクの使用許可が必要です
- 音声認識は「えー」などの言いよどみを一部拾えないことがあります。数値は目安として使ってください

## 技術構成

- HTML / CSS / Vanilla JavaScript(ビルド・依存ライブラリなし)
- 音声認識: Web Speech API(`SpeechRecognition`)
- データ保存: localStorage(端末内のみ)
